Personal Project

Clothing Owner Identification App

Built a web app to solve a common household problem: clothes getting mixed up between family members. Each garment is photographed and tagged with its owner, and TensorFlow.js extracts a visual embedding that is stored in a Supabase Postgres database using the pgvector extension. When a piece goes missing or gets swapped, a new photo is matched against the stored embeddings through vector similarity search, instantly identifying the rightful owner.

A simple and efficient attendance tracking system that uses face recognition, built with Python, OpenCV, and the face_recognition library. The app includes a module to register new people with their name and photo, an attendance module supporting both video-file processing and manual entry, a live system status display, and a daily attendance log.
